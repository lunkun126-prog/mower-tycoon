# 割草大亨（本地复刻版）

复刻 233乐园《割草大亨》（https://www.233leyuan.com/h5/2688365）的玩法与界面，three.js 自建低多边形模型，
不用原版美术素材；**无广告**，全部靠游戏内金币/钻石。2026-09-30 建。

- 启动：Launchpad「儿童游戏与学习 → 割草大亨」，或 `cd public && python -m http.server 8322 --bind 127.0.0.1`，打开 http://localhost:8322/index.html
- 端口 **8322**（已登记 `D:\claude\launchpad\PORTS.md`）
- 存档：浏览器 localStorage `mower_tycoon_v1`（设置 ⚙ 里可重置）
- 操作：按住屏幕拖动 / 方向键 / WASD

## 玩法（按原版实测）

割草装车（开局容量 360，装满后多割的掉地上、地面出白箭头指回基地）→ 基地「出售」（青草 0.275 金币/单位，360 块≈99）
→「升级」锯片（数量/锯齿/旋转速度）、卡车（容量/车轮）、拖车（3 级解锁）→ 割到 60% 拿第 1 星过关，80%/95% 拿金币/钻石
→「关卡」选 1~40 关（进新关场地重置）。5 级解锁商店（钻石买磁铁/加宽/售价+20%/新卡车/奖励翻倍，金币买 5 分钟助推器）
和农场（鸡舍吃青草产蛋、牛舍吃麦子产奶，拿去市场卖）。草越往后越硬：青草 → 麦子 → 芦苇 → 薰衣草 → 霜草，
锯片不够强时车变慢、锯片发红。

原版实测点与自拟数值都集中在 `public/js/config.js`；原版截图在 `docs/ref/`。
农场、商店的具体内容原版要 5 级才看得到，这里是自己设计的。

| 文件 | 内容 |
|---|---|
| `public/js/config.js` | 全部数值（草、升级价格、关卡生成、星星、商店、农场、车辆属性） |
| `public/js/world.js` | 场景：海、基地、建筑、地面格子、草场（实例化草 + 割草条纹贴图）、割草机模型 |

| `public/js/ui.js` | HUD 与各面板 |
| `tests/qa.py` | 无头验收 24 项：`py -3.11 -X utf8 tests/qa.py`（先起 8322） |
