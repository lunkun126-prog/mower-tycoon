# 割草大亨（本地复刻版 v4）

复刻 233乐园《割草大亨》（https://www.233leyuan.com/h5/2688365）的玩法与界面，在此基础上按自己的想法扩成
「割草 + 下水玩 + 农场经营」。three.js r170，模型用 CC0/CC-BY 的 glTF（见 `CREDITS.md`）+ 程序生成，贴图 ambientCG CC0。
**无广告**；默认 **沙盒模式**（金币钻石无限、40 关和所有设施全解锁，`config.js` 的 `SANDBOX` 可关）。2026-09-30 建。

- 启动：Launchpad「儿童游戏与学习 → 割草大亨」，或 `cd public && python -m http.server 8322 --bind 127.0.0.1`，打开 http://localhost:8322/index.html
- 端口 **8322**（已登记 `D:\claude\launchpad\PORTS.md`）
- 存档：浏览器 localStorage `mower_tycoon_v3_sandbox`（设置 ⚙ 里可重置）
- 操作：按住屏幕拖动 / 方向键 / WASD

## 玩法

1. **割草**：开上坡道进草场，割过的地面干净光滑（花也一起割）。锯片是尖钩齿。**难度**：1~10 关草稍硬（`config.js` 的 `hardness()`），
   **11 关起非常难**——草又硬又密，锯子要磨几下才断（锯了一半的草会变矮）、车在草里开不快（`dragOf()`），但一定割得动；
   升级锯片有帮助但效果递减（`cutPower()`），沙盒满级也不会变回一碰就断。10 种作物按关卡出现：
   青草 → 麦子 → 玉米 → 花生 → 胡萝卜 → 南瓜 → 向日葵 → 薰衣草 → 芦苇 → 霜草；场地从 40×44 米涨到 72×80 米。
   装满后多割的掉地上；割到 60%/80%/95% 拿三颗星，第 1 星解锁下一关。金草加金币，宝石加钻石。
2. **基地**：「出售」换金币；「升级」锯片（数量/锯齿/转速/尺寸）、卡车（容量/车轮/转向/吸草）、拖车、农场（扛草捆数/草料机效率/动物产量/货架容量/顾客人流）；「商店」；「关卡」。
3. **下水**：基地左边「下水」滑水道开进海里，拖拉机当场变成拖网渔船（上岸变回拖拉机），一家人都在船上。
   船头的网撞到鱼就捞进后备箱（金鱼/锦鲤/小丑鱼/鲫鱼/蓝金鱼/鲶鱼/鲨鱼/鳄鱼各有价，海豚和鲸只看不捞），
   撞到漂浮物算垃圾，回岸「出售」按鱼种卖钱、「倒垃圾」清空。
4. **农场**：车上的草开到「打捆」格 → 草料机打成草捆送进草棚。开进「农场」大门自动下车变成农夫：
   草棚扛草捆 → 鸡舍/牛舍喂草、收鸡蛋牛奶 → 「上架」放到货架 → 顾客从码头小路走过来买（付钱）。走回大门就上车。
   下车时带着后备箱里的生鱼，到「灶台」烤熟；鸡蛋/牛奶/烤鱼既能上架卖，也能自己吃回体力（体力低了走得慢）。
5. **一家人**：司机「一介草民（爷爷，男）」两手握方向盘坐驾驶位，后排长凳左「甜甜」（小女孩）右「岁月静好（奶奶）」并排同高坐，头顶头像名牌常显（`config.js` 的 `CHARACTERS`，头像在 `public/avatars/`）。
   坐姿用骨骼「指向」摆（`models.js` 的 `seatPose`，three.js 会把骨骼名里的点去掉：`UpperLeg.L`→`UpperLegL`）。
   到农场大门弹「谁下车」：点头像选一个或几个（第一个由你操控，其余跟着走），或「全家都下」；走回大门全都上车。
6. **车色**：每过一关换一种颜色（`CAR_COLORS`，着色器把车身贴图里的红色换掉）。拖车挂在后备箱后面的拖钩上，前后排开。
7. **小火车**（第 11 关起）：基地右边栏杆开口通到「小火车站」，环形铁轨。停到「装火车」格，草飞进三节车厢；车开走 2.5 秒（或装满）后
   小火车鸣笛出发，绕一圈穿过「市场」卖掉（比「出售」多 25%），再开回站台。参数在 `STATION` / `TRAIN`，代码 `public/js/train.js`。

数值全在 `public/js/config.js`；原版截图在 `docs/ref/`。

## 文件

| 文件 | 内容 |
|---|---|
| `public/js/config.js` | 全部数值（作物、关卡、升级、商店、农场、车辆/人物属性） |
| `public/js/assets.js` | 工具：随机数、材质、贴图、glTF 预载/实例化/骨骼动画/烘焙成可实例化几何 |
| `public/js/grass.js` | 草场：每种作物一个 InstancedMesh，风+车压 shader，割干净，花，宝石，装饰草坪 |
| `public/js/models.js` | 割草机（拖拉机 glTF + 锯片 + 后备箱 + 三个人物 + 渔船 glTF）、树、草垛、稻草人、动物、行人 |
| `public/js/world.js` | 场景：天、海、基地、建筑、滑水道、农场（石墙大门/草料机/草棚/鸡舍/牛舍/货架/码头） |
| `public/js/farm.js` | 农场玩法：下车/上车、打捆、扛草、喂养、收货、上架、顾客 |
| `public/js/main.js` | 主循环：操控、割草装车、出售、下水、存档、粒子、音效（WebAudio 合成） |
| `public/js/train.js` | 小火车站：站台、环形铁轨、蒸汽小火车、装车/发车/市场卖草 |
| `public/js/ui.js` | HUD 与各面板（含「谁下车」） |
| `tests/qa.py` | 无头验收：`py -3.11 -X utf8 tests/qa.py`（先起 8322，软件渲染约 10 分钟） |
| `tests/qa_v4.py` | v4 新功能验收（小火车、难度、选人下车、车色、坐姿、拖车）：`py -3.11 -X utf8 tests/qa_v4.py` |
| `tests/shot.py` | 快速截图到 `tests/shots/v_*.png`；`closeup.py`/`pose.py` 看车和坐姿近景 |
| `scripts/polypizza_*.py` | poly.pizza 模型搜索/下载（记录许可到 `tmp/models/manifest.json`） |
